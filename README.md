# Telegram File Store Bot

Deploy on Render Free:
1. Fork this repo
2. Create MongoDB free cluster
3. Create channel, add bot as admin
4. Deploy to Render, add env vars
5. Bot won't sleep due to keep-alive + web server

Admin Commands:
- /start - Start bot
- /batch 100 120 - Create batch from msg 100-120
- /special MovieName - Create special collection
- /admin - Open admin panel
